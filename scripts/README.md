# WalkBG API 脚本工具

这个目录包含了用于调用WalkBG API的各种shell脚本工具。

## 📋 脚本列表

1. **create_user.sh** - 创建单个用户
2. **create_map.sh** - 创建地图数据
3. **create_route.sh** - 创建路线（原版，包含默认数据）
4. **create_route_simple.sh** - 创建路线（简化版，只接收JSON）
5. **create.sh** - 完整路线创建主脚本（总入口）
6. **validate_route.sh** - 验证路线JSON数据格式（简化版）
