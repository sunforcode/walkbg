WalkBG 应用

欢迎使用 WalkBG 后台服务

这是一个基于 Spring Boot 和 Kotlin 构建的后台服务应用。

API 端点

  • GET /api/users - 获取所有用户
  • GET /api/users/{id} - 获取指定ID的用户
  • POST /api/users - 创建新用户
  • PUT /api/users/{id} - 更新指定ID的用户
  • DELETE /api/users/{id} - 删除指定ID的用户

数据库管理

本应用使用 H2 内存数据库。您可以通过以下链接访问 H2 控制台：

H2 数据库控制台
